Read documents on your own machine.

Nabu finds the fields on a scan, a phone photo, a PDF or an office file. It shows where each one is on the page, and you check and correct every field before it gives you a JSON file. Nothing leaves the machine, and Nabu never stores the values it reads.

Try the demo

Try the review window

This is Nabu's real review window, running in your browser on a made-up specimen licence. It reads nothing and sends nothing: the fields are already filled in, as Nabu would show them.

  1. Click a highlight on the card, or a field in the list.
  2. Check the Expiry Date, which is marked "needs review".
  3. Give the German Conditions an English value.
  4. Press Verify, save, and download the JSON.

On a small screen, open the demo full screen. The licence, its issuer "Musterland" and the person on it are invented.

How it works

1. Read

Nabu checks each file by its content, not only its name. It takes text from a PDF's text layer, reads scans and photos with OCR, and asks a vision model that runs on your machine to find the fields.

2. Review

Every field is highlighted on the page and says how it was found: from your template, suggested, needs review or not found. Rename, correct, remove, or draw a box to add a field. Labels get English names; names and ID numbers are never translated.

3. Output

After you verify, Nabu gives you one JSON file with the fields in reading order and each original value next to its English form. Optionally it also writes the file to a folder another program reads.

4. Learn

Save a verified document as a template. The next document with the same layout is read from the template, also from a photo framed or zoomed differently, and you only check it.

Private by design, enforced in code

  • Only this machine. While Nabu reads, any connection to another machine is refused, DNS lookups included.
  • The model runs locally. Nabu will not start if the model's address is not this machine.
  • No values on disk. Values live in memory and are gone when the document closes. Templates keep positions and labels, never values; Nabu checks every write for them.
  • Nothing leaves the window. The review window turns off spell-check and browser translation, and loads nothing from another site.
  • Logs say what failed, not what was read. Logs keep error types only, never messages or document text.

Limits apply. For example, a browser extension can read the window, and the operating system can page memory to disk. The README lists every known limit.
